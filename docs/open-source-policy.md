# Open-Source Policy

Prefer, in order: an unchanged upstream service/API, configuration, a thin derived image, an adapter, an upstream contribution, or a small separate fork. Copying source into this repository is a last resort that requires exact provenance and notices.

RomM remains in a separate AGPL-3.0 fork. Modified Selkies files remain under MPL-2.0. RetroArch and core distribution must satisfy their individual licenses. See `UPSTREAMS.md` and `THIRD_PARTY_NOTICES.md`.
