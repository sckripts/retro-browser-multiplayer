# Troubleshooting

If local Python commands fail, verify the `.venv` uses Python 3.14 and reinstall `requirements-dev.txt`. If container commands fail, start Docker Desktop and verify the Linux engine and WSL 2 integration before changing project configuration.

Milestone 18 runbooks are indexed in `docs/runbooks/README.md`. Start with the symptom's
runbook and preserve structured logs and UTC timestamps before recovery.
