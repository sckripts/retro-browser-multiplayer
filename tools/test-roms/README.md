# Test ROM policy

No test ROM is included in this repository, its images, tests, examples, or CI.

Milestone 2 uses Super Tilt Bro 2.6 by Sylvain Gadrat, licensed WTFPL-2.0. Run
`fetch-super-tilt-bro.ps1` to download the author's itch.io upload into ignored local
storage. The helper accepts only upload ID `16311760` and SHA-256
`847155bb712e474f71554174c9d9ed402bf651b13ff1e4afc9a42ec69cd03d8d`.
Full provenance is in `UPSTREAMS.md` and `images/retro-session/manifests/cores.yaml`.
